# VZ Studio 0.2.5.1 PBR 素材制作规范

“完美导出”的真实感取决于 **网格质量 + 法线 + 材质贴图 + 真实尺度 + 环境光照** 是否一致。程序会尽可能保持输入数据，但低分辨率贴图、错误的 Normal 方向、把高光/阴影烘进 BaseColor、错误的物理尺寸都无法靠渲染器完全补救。

## 1. 后台目录

标准安装下由程序自动创建：

```text
VZ_project/
└─ render_assets/
   ├─ textures/
   │  ├─ painted_metal/
   │  │  ├─ blue_basecolor.png
   │  │  ├─ blue_normal.png
   │  │  ├─ blue_roughness.png
   │  │  ├─ blue_metallic.png
   │  │  └─ blue_ao.png
   │  └─ rubber/...
   └─ environments/
      ├─ studio_soft_4k.jpg
      └─ factory_neutral_4k.jpg
```

如果设置过 `VZ_PROJECT_ROOT`，实际根目录随之变化；“完美渲染设置”和每个数模的渲染配置窗口都会显示当前后台素材库实际路径。复制文件后点击“刷新素材库”即可。

支持图片格式：PNG、JPG/JPEG、WebP。V0.2.5.1 尚不直接解码 `.hdr` / `.exr`。

## 2. 推荐每套材质准备的五张图

| 贴图 | 推荐内容 | 色彩/数值规则 |
|---|---|---|
| BaseColor | 纯材质本色，不包含灯光、高光、AO 阴影 | sRGB 彩色图；2K 起步，近景建议 4K |
| Normal | 微表面凹凸 | **OpenGL / +Y（绿色通道朝上）**；优先无损 PNG |
| Roughness | 表面粗糙程度 | 线性灰度；黑=光滑，白=粗糙 |
| Metallic | 金属/非金属掩码 | 线性灰度；金属通常接近白，塑料/橡胶接近黑 |
| AO | 微小遮蔽 | 线性灰度；白=无遮挡，黑=强遮蔽 |

五张图最好来自同一套扫描/PBR 材质，分辨率、裁切范围和纹理方向保持一致。不要混用不同网站/不同扫描尺度的 BaseColor 与 Normal。

## 3. 必须给出真实贴图尺寸

每个数模配置中的“贴图实际尺寸 mm”非常重要。它表示一张无缝贴图横跨的真实物理尺寸，而不是模型 UV 比例。

例如：细砂喷粉金属可从 80–200 mm 试起；拉丝金属的方向性更强，建议准备与零件方向匹配的材质；粗橡胶可从 50–150 mm 试起。最终应以真实样件照片作为尺度参考。

V0.2.5.1 对 STL/OBJ 通用材质采用 triplanar 投射，因此 STL 不需要 UV。对 Logo、文字、警示贴纸、铭牌、丝印、拉丝方向严格受控的表面，triplanar 不能代替精确 UV；建议做成独立薄片/几何，或在后续 GLB/UV 工作流中处理。

## 4. 环境图要求

环境图建议使用 **2:1 等距柱状全景**，例如 4096×2048 或 8192×4096。优先选择中性摄影棚、厂房或真实使用场景，避免过曝太阳、过强彩色灯和已经做过激进色调映射的素材。

环境图既影响背景也影响金属/清漆的反射质感。金属材质没有合适环境反射时，即使 metallic/roughness 数值正确也会显得“灰、塑料感”。

## 5. 数模本身的要求

- 机械锐边需要正确使用“硬边夹角”，默认 35°；真实倒角应由几何本身提供，法线不能创造不存在的倒角。
- 产品展示级模型建议保留真实的小倒角/圆角。完全数学锐边在现实中几乎不存在，会让高光不自然。
- 避免重复面、反法线、自交、极薄穿插面和严重非流形网格。
- STL/OBJ 的单位仍按现有 VZ 约定处理；贴图真实尺寸使用 mm。

## 6. 一套稳妥的用户配合流程

1. 每一种真实材料准备一套 2K/4K 无缝 PBR 五图。
2. Normal 必须确认是 OpenGL +Y；如果供应商只提供 DirectX Normal，需要先翻转绿色通道。
3. 准备至少一张 4K 2:1 中性环境全景。
4. 把素材复制到后台 `render_assets` 对应目录，在 UI 中刷新并逐数模选择。
5. 根据真实样件设置贴图实际尺寸、金属度/粗糙度；优先调 Roughness，其次才是 Specular/Clearcoat。
6. 先用高保真模式检查运动和构图，再用完美模式做最终交付，避免反复生成体积很大的单文件 HTML。

## 7. 单文件体积注意事项

完美模式只会内嵌当前项目实际引用的素材，但 Base64 会增加文件体积。很多 4K PNG Normal/AO 同时使用时，HTML 可能达到数百 MiB。推荐复用材质套装、避免无意义的 8K 图，并在肉眼看不出差异时优先 WebP/JPEG 用于 BaseColor/环境图；Normal 与灰度控制图优先保留足够精度。
