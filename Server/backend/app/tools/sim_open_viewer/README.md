# sim.open_viewer

生成当前项目的 XML/驱动/测距快照，并在独立 Python 子进程中打开 MuJoCo 原生 Viewer。

V2.2.1 在时间轴、倒放、倍速、撒点、测距胶囊线和电机解耦基础上提供距离标签、时间/电机数值定位、单/多 STL 整体质心轨迹、质心坐标读取，以及白底弹窗形式的跟随时间戳坐标系与甘特图。

V2.3.2 为甘特图增加后端可赋值的横向宽度和纵向行高，固定显示运动段起止时间与起止位置；游标读数使用红色粗体。跟随时间戳坐标系补齐时间横轴、数值纵轴、刻度和网格。

所有配置和控制动作投射自 `project.viewer_control`。原生窗口操作通过 `param.set` 回写统一命令总线；脚本或 LLM 给同一路径赋值即可远程控制已打开的 Viewer。

该工具不修改项目权威状态；桌面窗口内的临时播放/电机状态与 Web 服务生命周期彼此隔离。
